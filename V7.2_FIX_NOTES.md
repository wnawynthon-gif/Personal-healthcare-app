# V7.2 Fix Notes

V7.2 isolates the numeric Result cell more aggressively.

- Reduces crop height so adjacent lab rows are no longer included.
- Uses a tighter Result-column crop for the main table.
- Uses a separate Result-column geometry for the lower HbA1c/PSA table.
- Detects and removes long table border/rule lines before OCR.
- Adds stricter test-aware plausibility scoring.
- Suspicious OCR values are left blank instead of showing a dangerous guessed result.
- Full-page OCR can no longer replace a blank/suspicious isolated-cell result.
