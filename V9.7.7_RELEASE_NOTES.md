# V9.7.7 — Private accounts and automatic sync

- Stores local health data under the signed-in user's unique account ID.
- Prevents the next account on a shared device from seeing the previous account's data.
- Loads the user's cloud snapshot automatically after login.
- Saves changes to the user's private cloud snapshot automatically.
- Hides account data immediately on sign out.
- Migrates the original owner's legacy local data once, after their first login.
- Keeps Supabase and AI deployment configuration hidden from normal users.
