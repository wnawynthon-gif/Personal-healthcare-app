# V9.8 — Resilient multi-device sync

- Checks Cloud for newer health data after login, reconnecting, and returning to the app.
- Keeps local and Cloud timestamps so an older device cannot silently overwrite newer data.
- Merges records from both devices during the one-time upgrade or a true concurrent-edit conflict.
- Refreshes expired Supabase login sessions automatically and retries a failed authenticated request once.
- Disables manual sync buttons while signed out and shows clearer Thai sync status messages.
- Preserves private per-account local storage and the existing v9.7 health, blood-pressure, weight, AI, and backup features.
