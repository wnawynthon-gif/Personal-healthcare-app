# V6.5 Smart Lab Importer

Fixes based on the photographed Health Check import failure seen in v6.4.

- Runs OCR at a larger working resolution and performs a second high-contrast numeric pass.
- Checks multiple image rotations for HEIC/JPEG photographs.
- Restricts automatic lab rows to a canonical medical test dictionary.
- Separates reference bounds from patient results and rejects a result that equals a known reference boundary.
- Scores nearby numeric candidates instead of blindly taking the first number after a test name.
- Marks every OCR-derived row as requiring verification and never preselects it.
- Shows a visible warning when extraction is ambiguous or reference/result collision is suspected.
- Saves newly confirmed rows as `document-import-v6.5`; these are not quarantined as legacy OCR data.

Safety rule: when the source OCR does not contain a trustworthy patient result, v6.5 leaves the value unresolved rather than inventing a result.
