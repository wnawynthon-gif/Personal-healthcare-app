# Quick test
1. Deploy v6.2 and hard-refresh the GitHub Pages site.
2. Open `ผลตรวจ`.
3. Choose a clear JPG/PNG lab report or a PDF.
4. Wait for extraction/OCR.
5. Review raw text.
6. Review every detected row and edit incorrect names, numbers, units, dates, or references.
7. Tick only rows you want.
8. Press `ยืนยันและบันทึกผลที่เลือก`.
9. Open `วิเคราะห์สุขภาพ` and verify the results.
10. Use Cloud Sync only after confirming the imported results are correct.
