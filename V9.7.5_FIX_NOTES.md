# V9.7.5 — Permanent mobile login configuration

- Added `config.js` as the single deployment configuration source.
- Supabase Project URL and publishable/anon key now load automatically on every
  browser, including iPhone Safari.
- Kept the existing local setting as a fallback for older deployments.
- Improved missing-field and missing-configuration errors.
- Hid Sign out until a valid login session exists.
- Bumped all cache versions so mobile Safari receives the fixed files.

Before publishing, put the Project URL and **publishable/anon** key in
`config.js`. Never put a `service_role` key in browser code.
