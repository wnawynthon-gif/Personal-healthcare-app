# V9.8.1 — Medication photo AI and reminders

- Adds a guided medication workflow: Camera/Photos → AI extraction → Review/Edit → Confirm → Reminders.
- Extracts brand name, generic name, strength, dosage form, printed directions, frequency, meal relationship, dates, and editable reminder-time suggestions.
- Supports multiple reminder times for one medicine while remaining compatible with older single-time records.
- Updates an existing matching medicine instead of silently creating a duplicate.
- Stores one compressed reference thumbnail per photo import and syncs it with the private account snapshot.
- Adds manual medication editing, date ranges, notification permission/status, and in-app/PWA notification timers.
- Keeps an explicit warning that AI extraction must be checked against the original label and is not authority to start, stop, or change medication.
- Includes an updated `analyze-health-report` Supabase Edge Function that preserves health-report analysis and adds the `medication_label` task.
